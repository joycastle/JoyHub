# 指定部门使用权限

资源保持一个维护归属部门，使用范围可以包含多个部门。共享不会赋予编辑、发布或管理权限。

## 工具和 Agent

编辑资源时，在归属设置下勾选“指定使用部门”。所属部门始终保留使用权限，额外部门可以跨维护者所属部门选择。公共库资源可以选择“仅指定部门可用”，至少选择一个有效部门。

保存后，指定部门成员可以在 JoyHub 中搜索、查看和下载已发布的资源。移除部门后，其成员不再通过该部门获得访问权限；若仍属于其他被授权部门，则继续可用。草稿、下线与归档状态不因共享而变化。

只有原有维护者或有权管理员能修改资源。部门共享不会改变发布归属限制，不能借此把资源归属到自己无权发布的部门。

## Skill 包

Skill 的维护命名空间仍是单一的 `namespace_id`。技能详情页的“部门访问权限”面板允许技能所有者、维护命名空间的 `ADMIN`/`OWNER` 或超级管理员打开“仅允许选中的部门访问”，再选择多个启用中的非全局部门；保存后这些部门成员可以搜索、查看详情、复制安装命令并下载已发布版本。被授权部门成员只有使用权限，不会获得编辑、发布、标签或共享管理权限。

关闭限制是显式操作；限制开启后即使目标列表为空，也不会恢复匿名公共访问，只保留维护命名空间（全局维护命名空间的普通成员不自动获得访问权）。

Skill 的搜索、详情、下载以及 CLI/Agent 兼容读取路径共用同一份可见性判断。存在显式共享部门时，公共技能不再对匿名访问开放；维护命名空间成员与显式目标部门成员仍可访问。共享目标列表由登录用户从 `/api/web/sharing-targets`（或 `/api/v1/sharing-targets`）读取，管理接口为 `GET`/`PUT /api/web/skills/{namespace}/{slug}/sharing`。

## 边界

JoyHub 中的可见性和下载授权不替代外部网站、飞书应用或工具自身的登录与授权。外部 URL 以及独立静态托管入口需要由相应服务执行访问控制。已下载到本地的文件不能远程撤回。
